Human RNome Project - RNA Sequence

This track displays individual poly(A) RNA reads aligned to the human genome (hg38), visualized as a sequence track using the bigPSL format. Each item represents a single read with its nucleotide sequence embedded, enabling base-level inspection of RNA sequence content.

Reads were derived from BAM alignments converted to PSL format using bamToPsl, then indexed as bigPSL. The track is annotated with an adjacent modification decorator layer (HRP_decorator) that marks each RNA modification call at base resolution, allowing direct comparison of sequence context (such as DRACH motifs associated with m6A) with detected modification sites.

Display Conventions and Configuration

By default, bases are colored by their identity (A, C, G, T/U), using the standard UCSC base color scheme. To switch to difference highlighting (mismatches vs. reference only), use the "Color track by bases" dropdown in the track controls. Zoom in to single-base resolution to view individual nucleotides.

Modification calls are shown as colored blocks adjacent to each read, colored by modification type according to the table below. The decorator is displayed in adjacent mode by default, placing modification marks below the read sequence rather than on top of it. Set track visibility to "pack" (default) for labeled reads, or "squish" for a compact view.
