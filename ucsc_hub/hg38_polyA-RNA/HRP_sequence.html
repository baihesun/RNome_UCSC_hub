Human RNome Project — RNA Sequence

This track displays individual poly(A) RNA reads aligned to the human genome (hg38), visualized as a sequence track using the bigPSL format. Each item represents a single read with its nucleotide sequence embedded, enabling base-level inspection of RNA sequence content.

Reads were aligned from BAM files using bamToPsl and converted to bigPSL format. The track is overlaid with a modification decorator layer (HRP_decorator) that annotates each read with RNA modification calls at base resolution, allowing direct comparison of sequence context — such as DRACH motifs associated with m6A — with detected modification sites.

Display Conventions and Configuration

Bases are colored by sequence identity relative to the reference genome: mismatches are highlighted in color, while reference-matching bases are shown in grey. Use the "Color track by bases" option (track controls) to switch between display modes. Zoom in to single-base resolution to view individual nucleotides.

The overlaid modification decorator shows RNA modification calls as colored blocks. Set visibility to "squish" (default) for a compact read display, or "pack" for labeled reads.
