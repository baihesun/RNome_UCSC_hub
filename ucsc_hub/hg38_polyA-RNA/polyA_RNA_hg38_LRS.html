Human RNome Project — poly(A) RNA long-read sequencing

This track includes predicted RNA modifications using ONT dorado modification-aware basecalling models. RNA modified sites were grouped into two tiers: i) tier 1 Reflects sites which show a significant modification level change between IVT and native RNA; ii) tier 2 reflects sites which did not have IVT with sufficient coverage, but showed a score >0.9 derived from the equally weighted sum of min max normalized log2(coverage), modification level and model confidence ranks.

Display Conventions and Configuration

Items are colored by modification type; within each modification type, color saturation is proportional to modification frequency — vivid colors mark high-frequency (high-stoichiometry) sites, pale colors mark low-frequency sites. Modification types not shown in the color key below are rendered in gray (#808080).
